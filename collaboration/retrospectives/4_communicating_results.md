# Milestone 4 Retrospective: Communicating Results

## 📋 Stop Doing

- Waiting until final days to consolidate presentation feedback
- Creating slides without first agreeing on core narrative structure
- Parallel work on communication artifacts without daily syncs
- Over-designing visualizations before validating key messages

## 🔁 Continue Doing

- Peer review exchanges with other groups
- Using SHAP visualizations to explain risk factors
- Maintaining centralized documentation of changes
- Time-boxed collaboration sessions (2-hour sprints)

## 🚀 Start Doing

- Creating audience-specific message hierarchies
- Recording video walkthroughs of key insights
- Developing "What This Means" summaries for non-technical stakeholders
- Implementing version control for presentation assets

## 💡 Lessons Learned

1. **Constraints drive clarity**:The 6-slide/90-second limitation
                                 forced sharper messaging
2. **Visuals > Text**: SHAP plots communicated more than tables of feature importance
3. **Audience determines medium**: Different stakeholders need tailored artifacts
4. **Feedback loops are essential**: Early peer reviews exposed gaps
                                     in narrative flow
